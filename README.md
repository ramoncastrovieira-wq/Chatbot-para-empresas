TICO CRM - Autopeças

Setup rápido para demonstração:

1. Instalar dependências

```bash
npm install
```

2. Rodar o servidor

```bash
npm start
# ou em desenvolvimento com nodemon
npm run dev
```

Abra http://localhost:3000

Funcionalidades básicas:
- Cadastro de clientes
- Catálogo de peças (CRUD básico)
